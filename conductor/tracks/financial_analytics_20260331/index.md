# Track: Financial Analytics & Data Visualization

## Overview
This track replaces static metric cards with dynamic visual intelligence. It provides owners with real-time revenue trends and occupancy analytics to drive better business decisions.

## Strategy
1.  **Data Extraction:** Build a server action to aggregate booking revenue by date for the last 30 days.
2.  **Visualization Library:** Integrate `Recharts` for high-performance React charting.
3.  **UI Upgrade:** Replace dashboard placeholders with live Bar and Area charts.

## Acceptance Criteria
- [ ] Owner Dashboard displays a "Revenue vs Date" line or bar chart.
- [ ] Dashboard displays an "Occupancy Trend" chart for the current month.
- [ ] Charts dynamically update when the property switcher is used.
- [ ] Accurate calculation of ADR (Average Daily Rate) and RevPAR (Revenue Per Available Room).
